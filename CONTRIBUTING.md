# Como contribuir
## Commits
Exemplo: `feat(obras): adiciona a rota GET /api/obras #20`

| Tipo | Quando usar |
| --- | --- |
| `feat` | Funcionalidade nova para o utilizador |
| `fix` | Correção de um erro |
| `test` | Testes novos ou alterados |
| `docs` | Só documentação (README, ADR, AI_LOG) |
| `ci` | O pipeline de CI (`ci.yml`) |
| `refactor` | Reorganizar código sem mudar o que faz |
| `chore` | Manutenção: dependências, configuração, pastas |
